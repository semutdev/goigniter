## Mengapa Goigniter?

<CardGrid stagger>
  <Card title="Struktur MVC" icon="pencil">
    Controllers, models, views — terstruktur rapi. Tanpa magic, tanpa kejutan.
  </Card>
  <Card title="Performa Go" icon="rocket">
    Binary compiled, concurrent secara bawaan. Ribuan request dengan memory MB-an.
  </Card>
  <Card title="Auto Routing" icon="setting">
    Buat controller, tambah method, langsung jadi route. Tanpa boilerplate.
  </Card>
